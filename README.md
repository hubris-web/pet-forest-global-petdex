# Pet Forest Global Petdex — Beta 0.2

A community-maintained Pet Forest Global pet reference built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import this project into Vercel. The project root is this folder (the folder containing `package.json`).

## Data accuracy

- Pet records are transcribed from supplied in-game screenshots and should be checked against the game.
- Only the first and second innate skills are displayed in the innate skills section.
- Missing skill descriptions are intentionally left as unavailable; no effects are invented.
- Pet comparison and cultivation features are not included.
